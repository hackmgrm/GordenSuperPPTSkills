# GordenSuperPPTSkill

依次执行两个同级子技能，交付图片型 PPT + 混合可编辑 PPTX + 实际素材：

1. [GordenImagePPTGen](../GordenImagePPTGen/SKILL.md)：用 imagegen 逐页生成带完整文字的成品图。保留原图、提示词与 imagegen-manifest.json，不用代码绘图或原生PPT截图冒充此阶段。
2. [GordenImage2PPTX](../GordenImage2PPTX/SKILL.md)：按元素选择 native 或 image。普通文字和简单线条/几何对象原生重建；复杂照片、纹理、光效和艺术字使用图片。不存在的层不用生成。
3. 按 [pipeline.md](references/pipeline.md) 验收交付。结构、透明层、内容视觉和真实应用渲染分别记录，未做项目明确说明。

用户只要图片版则只执行阶段1；只转换已有图片则只执行阶段2。用户明确选择原版图片层模式时按该模式执行，并解释可编辑边界。

## 关键约束

- 内容以用户原文为准，品牌、数字、路线代码与单位要逐项校对，不编造数据或二维码。
- 两阶段比例统一；风格统一优先于每页强行换一种复杂框架。可复用卡片语言，按内容变化布局。
- 用户已给齐风格/受众/页数时直接执行；缺少LOGO/二维码可先制作并明确标记待补资产，不假造。
- 先验证代表页，再扩展整本。局部修复不重新生成无关页面。
- 最终准确区分原生文本/形状与可移动图片；保留上游署名，不承诺完全可编辑或完美复刻。
