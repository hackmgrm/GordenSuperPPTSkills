# 运行时说明

优先使用用户指定的图像后端；Codex 中使用可用的 imagegen 工具。按当前工具实际参数传入图片，不能把文件路径写进提示词当作附件。先查看源图再编辑。

复杂图片层需要图像工具；没有可用工具时说明受影响部分，不用程序绘图冒充生成。纯色背景、简单原生形状和文本不依赖图像生成，不必因此阻塞已授权的原生重建。

工具支持透明输出时优先尝试，并检查文件实际 alpha；否则选择与内容不冲突的色键，用 chroma_key.py 去底。不要给已透明图片再次抠色。

保留工具返回的生成原件，复制到独立任务目录。来源清单记录实际 backend、源路径、复制路径、提示词和透明方式；用户提供的资产与 native 对象分别标记，不伪造图像调用。

依赖：Python 3、python-pptx、Pillow、numpy。两个子技能各自携带合成脚本以支持独立安装；改合成器共享逻辑时需同步并执行仓库 tests。

比例跟随用户，默认16:9。图像工具输出与目标比例不一致时优先重新生成，不把整页文字/图表拉伸到目标比例；轻微差异也要实际检查。源图坐标以实际尺寸为准。

只在当前环境有对应工具时使用 PowerPoint/LibreOffice 实际渲染；Pillow 输出是近似预览，字体、runs换行、旋转及阴影仍可能不同。
